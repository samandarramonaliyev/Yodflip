# Yodflip 🃏

Vocabulary games for Uzbek-speaking learners of **English** and **German**, as a responsive website **and** a Telegram Mini App, with one backend and one account system.

> 🇺🇿 [O'zbekcha qisqacha pastda](#-ozbekcha)

- 📸 **Photo → game**: snap a vocabulary page, review the extracted word–definition pairs, play the Match Game.
- 🃏 **Match Game**: words on top, same-language definitions at the bottom, 3D flips, rounds of 4–8 pairs.
- 📚 **Built-in levels** A1–C1 per language: 600 words with definitions, Uzbek translations and examples, in themed packs. The next level unlocks at 70%.
- 🗂️ **My Decks** (Quizlet-style): bulk paste, CSV import/export, share links, Flashcards / Learn / Write, text-to-speech.
- 🎮 **Memorization games** (word ↔ Uzbek): Speed Match, Word Builder, Falling Words, Memory Pairs, Der·Die·Das (German only), Review (Leitner), Daily Challenge with a global leaderboard.
- 🔥 XP, levels, streaks, badges, leaderboards. UI in Uzbek (default), English and Russian. Light/dark themes plus Telegram theme colours.
- 🤖 Telegram bot (`/start`, `/daily`, `/stats`, `/review`, `/remind`) running **inside Django** in webhook mode.

## Architecture

One deployable service: **Django serves the API, the built React app and the Telegram bot webhook.**

```
backend/                   Django 5 + DRF + SimpleJWT + drf-spectacular, gunicorn
  config/                  settings (fail-closed in production), urls, test settings
  core/                    health check, SPA view, DB-backed media storage, seed-once marker
  accounts/  telegram_auth/  users, email + Telegram login (initData / Login Widget HMAC)
  words/  decks/  games/   levels & seed, Leitner lists, decks & scans, game rules/scoring
  ocr/  gamification/      Claude vision OCR (+ Tesseract / mock fallbacks), XP/streaks/badges
  telegram_bot/            aiogram 3 handlers, /bot/webhook/<secret>/, /bot/cron/<secret>/
  gunicorn.conf.py         registers the Telegram webhook on startup
frontend/                  React + Vite + TS + Tailwind + Framer Motion (relative /api calls)
build.sh                   Render build: pip → npm build → collectstatic → migrate → seed once
render.yaml                single Render web service (free plan); database: Neon via DATABASE_URL
```

## Local development

```bash
cp .env.example .env                              # contains DEBUG=true (required locally)

cd backend
python -m venv .venv && .venv/Scripts/activate    # macOS/Linux: source .venv/bin/activate
pip install -r requirements-dev.txt
python manage.py migrate && python manage.py seed_words
python manage.py runserver                        # http://localhost:8000

cd ../frontend
npm install
npm run dev                                       # http://localhost:5173 (proxies /api to :8000)
```

Open **http://localhost:5173**. Swagger: http://localhost:8000/api/docs/ · Admin: http://localhost:8000/admin/ (`python manage.py createsuperuser`).

**Mock mode** (`DEBUG=true`, no keys): scans return sample word pairs and the login page offers a demo Telegram login.
The real Telegram bot needs a public HTTPS URL, so test it on Render (or via a tunnel with `PUBLIC_URL` set).

Optional production-like run (Docker): `docker compose up --build` → http://localhost:8000.

## Tests and lint

```bash
cd backend  && pytest && ruff check .              # tests use config.test_settings (no .env needed)
cd frontend && npm test && npm run lint && npm run build
```

## Environment variables

See `.env.example`. The important ones:

| Variable | Purpose |
|---|---|
| `DEBUG` | `true` locally only. With `false`, `SECRET_KEY` and a PostgreSQL `DATABASE_URL` are required |
| `SECRET_KEY` | Django secret (generated by Render) |
| `DATABASE_URL` | Neon / PostgreSQL connection string (`?sslmode=require`) |
| `ALLOWED_HOSTS`, `CSRF_TRUSTED_ORIGINS`, `PUBLIC_URL` | auto-filled on Render; set them for a custom domain |
| `ANTHROPIC_API_KEY`, `ANTHROPIC_MODEL` | Claude vision OCR for photo scans |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_BOT_USERNAME` | bot + Mini App login + website Login Widget |
| `TELEGRAM_WEBHOOK_SECRET`, `BOT_CRON_SECRET` | path secrets for the webhook and the reminder cron (generated by Render) |
| `OCR_DAILY_LIMIT`, `TIME_ZONE` | scans per user per day (20) · day boundary (Asia/Tashkent) |
